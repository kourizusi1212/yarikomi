# NEON SURVIVORS ONLINE

みんなで協力して、押し寄せる敵を何ウェーブ耐えられるかに挑むリアルタイム・サバイバル。

## 遊び方
- 移動: WASD / 矢印キー(スマホは画面ドラッグ)。攻撃は自動。
- 敵を倒すと出る経験値を拾ってレベルアップ → 3択の強化を選ぶ(1/2/3キーでも選択可)
- 5ウェーブごとにボス。全員やられるとリセット、ランキングに記録
- 死んでも獲得ゴールドで「永続強化」(ブラウザに保存)、3種のクラスで毎回違う遊びができる

## ローカル起動
    npm install
    npm start   # http://localhost:3000

## GitHub → Render
1. このフォルダをそのままGitHubリポジトリにpush
2. Render: New + → Web Service → リポジトリを選択
   (render.yaml があるので設定は自動。手動なら Build=`npm install` / Start=`npm start`)
3. 発行されたURLを友達に共有すれば同じ部屋で遊べます
※ 無料プランは放置でスリープし、ランキング(data.json)は再起動で消えます。
